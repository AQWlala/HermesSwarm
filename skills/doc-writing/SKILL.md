# Documentation Writing Skill

Generate clear technical documentation for code, APIs, and features.

## When to Use

Use this skill when the user asks to write docs, document an API, or create a README.

## How to Run

1. Read the target code to understand its interface and behavior.
2. Identify the audience (developer, user, operator).
3. Generate documentation with examples.
4. Verify examples are correct and runnable.

## Quick Reference

- Input: code path or API description
- Output: markdown documentation
- Tools: `read_file`, `search_files`
